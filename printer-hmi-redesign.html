3D 打印机智控屏
界面重设计方案

以原屏信息架构为骨架，保留用户的操作惯性；在此基础上重构视觉层级、语义色彩与触控体验——让「扫一眼即知状态，伸手即达操作」。

  • 美观克制的工业仪表感，颜色只用来表达含义
  • 易用大触控热区 + 参数就地编辑
  • 符合习惯延续原布局骨架与「绿色 = 开启」的色彩心智

基准分辨率 1080 × 720（3:2 触摸屏）· 深色 HMI · 下方原型可直接操作

A · Audit

现状诊断：六个核心问题

基于实拍截图逐项走查（布局、色彩、排版、触控、反馈），每条问题附带对应的设计对策。

01

色彩没有语义

八个指标用了八种颜色，"外排 65%" 的红色只是风扇速度，却会被误读为告警。

→ 按物理量家族分配色相：青 = 气流、橙 = 温度、蓝 = 湿度、紫 = 电气；告警用状态灯独立编码。

02

信息层级扁平

最关键的「打印中」状态只是一行小字，与普通设置项视觉重量相同。

→ 顶部重组信息带：状态胶囊（呼吸灯）+ 大号时钟；材料切换降为次级。

03

参数"只可远观"

最低 / 最高阈值仅作展示，触摸屏的交互价值被浪费。

→ 阈值就地步进编辑：± 按钮、长按连发、立即生效。

04

触控目标偏小

开关与底栏按钮低于 48px 推荐热区，快速操作或戴手套时误触率高。

→ 开关 56×32、底栏整高 88px、步进按钮 26px 成组出现，全部满足热区要求。

05

数字抖动

时钟与读数使用比例数字，每次刷新宽度变化，画面持续"发抖"。

→ 全部数字改用 Saira 等宽数字（tabular-nums），读数稳定如仪表。

06

缺少趋势与量程

"65%" 无从判断是偏高还是正常，异常只能靠用户记忆对比。

→ 每个指标带量程进度条 + 阈值刻度线 + 趋势箭头，状态一眼可判。

D · Handoff

交付说明：落地与验证

  • 字体：数字 Saira（tabular-nums 防抖动），中文 Noto Sans SC；离线时回退系统字体，版式不塌。
  • 图标：24px 网格、1.8px 圆头描边，颜色随语义 token 走，不单独配色。
  • 动效：开关 200ms、阈值条 600ms ease、状态灯呼吸 1.8s；全局遵循 prefers-reduced-motion。
  • 可访问性：全部文本对比度 ≥ 4.7:1（WCAG AA），大号读数 ≥ 5.4:1；信息不只靠颜色承载（状态灯 + 刻度 + 趋势）。
  • 适配：1080×720 基准 + 8pt 网格，整机等比缩放；触控热区 ≥ 44px，核心开关 56×32。
  • 验证：原型已在本机浏览器实测（渲染 / 交互 / 模拟数据正常）；交付格式为单文件 HTML，可直接投屏评审。
