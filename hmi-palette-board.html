配色方案板：按审美家族铺开

每一套都含日间 + 夜间两组完整变量，同色相贯穿双模。点色带复制单个色值，点按钮复制整段双模 CSS。
挑的时候别看单个色块——先看它给你的感觉，再回来对 hex。

页面主题

为什么上一版"不好看"

  • 6 套全是同一气质：低饱和 + 灰蓝中性色，换色相不换审美
  • 中性色是"中性灰"，没有跟着主色偏色，画面发灰
  • 主色不够饱和，缺少一个明确的视觉焦点

这一版改了什么

  • 按家族分组：工业 / 科技 / 复古 / 自然 / 极简，气质先分野
  • 中性色跟着主色带一点同向色偏，整体不再发灰
  • 科技与霓虹家族把饱和度拉满，极简家族只留一个跳色

日间 / 夜间的四条规则

  • 夜间不用纯黑底、纯白字；卡片比底色亮一层做分层
  • 日间靠描边分界，夜间靠明度分界
  • 状态色两种模式各一套：#DC2626 → #F87171
  • 导出 CSS 三层优先级：手动指定 > 系统偏好 > 日间兜底
