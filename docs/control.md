# 温控与功率安全

控制器由主循环每 50 ms 调用一次。仓温 PID 与发热板 PID 在同一周期、使用同一个
采样时间 `dt` 计算；`dt` 被限制在 10–250 ms，避免偶发调度抖动放大积分或微分项。

## 双 PID 协同

- 仓温 PID：设定值为当前耗材的最低仓温，输出代表加热需求。
- 发热板 PID：设定值为“发热板温度保护”，输出代表当前允许的安全功率。
- 合成输出：`min(仓温 PID, 发热板 PID, 用户功率上限)`。

因此，即使仓温仍然较低，只要发热板接近保护温度，最终功率也会受发热板 PID
限制。发热板达到保护阈值或仓温达到耗材最高温度时，状态机进入安全排气并立即
停止加热；PID 只是渐进控制，不能替代硬保护。

## 过流软降

INA226 电流读取使用绝对值，兼容采样方向相反的接线。当电流超过设置上限时：

```text
限流后功率 = PID 合成功率 × 设定电流 / 实测电流
```

该比例在阈值处连续，不会像硬切断一样造成输出反复跳变。限流后的目标还会经过
每 50 ms 最大 3% 的 PWM 斜率限制，逐步降低功率。INA226、NTC 或 AHT20 任一安全
输入无效时不使用软降，而是当周期立即输出 0；传感器恢复后从 0% 重新爬升。

## PID 状态清理

待机、检测、冷却、故障、关闭自动温控或传感器无效时，两个 PID 的积分、微分历史
与 PWM 历史都会清零，避免长时间停机被错误计入下一次温控。
