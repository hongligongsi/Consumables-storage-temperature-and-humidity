固件激活

注册码由芯片 ID 离线派生（一机一码），本页面不联网、不上传任何数据。 芯片 ID 显示在设备「系统设置 → 芯片ID」与注册码页顶部，格式 CH- + 12 位十六进制。

屏幕中显示的芯片 ID，如：CH-1A2B3C4D5E6F。请务必填写准确，否则注册码将无法通过校验。

芯片 ID 格式不正确：应为 CH- + 12 位十六进制（0-9 / A-F）。

该设备的注册码
--------

✓ 匹配：该授权码可用于此芯片 ID 的设备。

✗ 不匹配：授权码与芯片 ID 不对应，请核对两处输入。

算法：FNV-1a-64(chipId + 盐) 取低 32 位，8 位大写十六进制；与固件 pure::regCodeFromChipId()（include/pure_logic.h）及模拟器 tools/ui_preview.html 为同一实现，改动须三处同步。
