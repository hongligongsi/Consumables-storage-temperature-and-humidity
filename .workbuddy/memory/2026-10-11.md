## 用原理图逐格核对 12 项（用户说"确认不了,你给我解决"）

**方法**:`hardware/sch-p1-2026-01-30.png` 是 3172×3172,用 PIL 裁块 + 2~4 倍 LANCZOS
放大后 Read 就能当放大镜用(裁剪脚本产物放 `C:\Users\hongliwang\.workbuddy\tmp\schcrop\`,
**别放进项目目录**,白名单 .gitignore 会收进主仓)。9 块:MCU / 屏幕排线 / ADC 采样 /
直流加热 / 排气扇 / 风扇 / 电源 / MCU 下排引脚。

**核对结果(全部与 pins.h 一致)**:
- MCU:IO3=ADC_NTC,IO4~7=TFT_YD/XR/YU/XL,IO15/16/17=EC_D/B/A,IO18=RGB,IO35=PIR,
  IO36=HOT_FAN,IO37=LED,IO38=AIR_FAN_DC,IO39=AIR_FAN_PWM,IO40=HOT_PWM,IO41/42=SCL/SDA,
  IO45=BOARD_FAN,IO47=状态输出;下排 15~23 = ADC_NTC/TFT_RES(9)/SDO(10)/SDI(11)/SCK(12)/DC(13)/CS(14),
  23=BL(21)
- 热板 NTC:R14=10kΩ 上臂;板上 R17 标 "10kΩ 3950K" 但**画叉未贴**,NTC 走 CN3 外接 → β=3950 有依据
- I²C 上拉 R2/R3=5.1kΩ → "上拉缺失"基本可排除
- 直流加热:INA226AIDGSR 图纸注明 Addr 0x40(A1/A0=GND);**R15 = 5 mΩ**;
  U9=JSM27517 隔离驱动(12V)推 Q3 → HOT_PWM 高电平有效
- 排气:AIR_FAN_DC→Q4 低边(R21 100k 下拉);CN5=2线DC调速 / CN6=4线PWM;
  风扇电源 U12/U13 短路点选 24V 或 12V
- 显示:FPC-05FB-40PH20,3.5" ST7796 320×480,版本"不带触摸/带触摸";BL→Q1(S8050) 低边,高占空比=亮
- 状态输出 IO8/47 只到 H2/H3 排针,**无驱动**
- 电源:24V 主入 → XL4015E1(12V)/ME3116AM6G(5V)/AMS1117(3V3)
- 灯:4 颗 XL-5050RGBC-2812B 串联 ✅

**⚠️ 发现并修正一个真实错误**:代码 `SHUNT_OHMS = 0.01f`(10 mΩ),图纸 **5 mΩ**。
校准寄存器 = 0.00512/(LSB×Rshunt) → 写小一半 → **电流读数只有真值一半**,
限流要 2× 才动作、硬过流(1.5×)整体延后一倍 —— 安全相关的实质 bug。
已改 `include/ina226_sensor.h` 的 `kShuntOhms=0.005f`(+ `kCurrentLsbA`),类外定义保 C++11/17。

**新增串口 'd' 硬件自检**(main.cpp,只读不开加热):ADC raw 与换算、0x38/0x40 ACK、
AHT20 是否 fresh、分流与 cal 值、bus/current、输出百分比、输出脚电平回读(P8/47/38/45/37/40/36/39)。
把阶段 1~3 从"拿表逐脚量"降成一条命令。**输出必须全 ASCII** —— 中文字面量会被
genvlw.py 收进字库。

**还离不开万用表的只剩两项**:第 2 项 NTC 的 25℃ 阻值;第 4 项量一次 R15 证实 5 mΩ。
